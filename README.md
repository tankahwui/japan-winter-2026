# Japan · Winter 2026

Personal trip website with flights, accommodation, an interactive map and recommendations grouped by four stays.

Open `index.html` through a static web server. No build step is required. Edit `app.js` for bookings and map places, `itinerary.js` for accommodation-based recommendations, and `style.css` for styling.

This copy contains personal travel details. Keep the repository private unless you intend to share them. Publishing requires a separate hosting choice.
